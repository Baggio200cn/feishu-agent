# 图标资源目录

将以下图片文件放入本目录，GUI 启动器会自动加载（缺失时使用 emoji 兜底）：

| 文件名     | 用途                        | 推荐尺寸  |
|------------|----------------------------|---------|
| icon.ico   | 窗口任务栏图标 (Windows)    | 32×32   |
| icon.png   | 窗口图标备用 (跨平台)        | 32×32   |
| logo.png   | 启动器顶部 Logo              | 48×48   |
| agent.png  | 聊天窗口助理角色图标          | 36×36   |

支持格式：PNG、ICO（需要 Pillow 库以支持缩放）。
安装 Pillow：`pip install Pillow`
